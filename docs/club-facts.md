# Club facts to check (M1)

Every factual claim the website makes about the club, for the team manager to confirm or correct. We go through
it together, one at a time. For each: **Confirmed?** yes / no / don't know, and the **correct value** if it's
wrong.

- **Confirmed** facts stay, and become the seed values in Sanity (editable later in the Studio).
- **Corrected** facts are changed in Sanity (and in `fallback.ts`, which seeds it), or in code if they are wording.
- **Don't know** facts come out of the site.

_Source_ is where the claim lives today. _Sanity field_ is where the team manager will edit it (Studio item →
field); "code" means it's page wording, changed by the developer. Demo content (`demo.ts`) is sample data, not
facts, and isn't listed. File paths are under `apps/web/src/` unless they say otherwise.
